# LEX-INDIC: PHASE 2 — PROFESSIONAL PDF CASE BRIEF GENERATOR

## What Phase 2 Produces
A single downloadable `.pdf` file per client — the **"Case Brief"** — that a
law firm can print, file, and hand to a client in under 60 seconds.

---

## The PDF Layout (Page by Page)

| Page | Section | Content |
|------|---------|---------|
| 1 | Cover Page | Lex-Indic logo, Law Firm name, Client name, Date, Confidential stamp |
| 2 | Immediate Advisory | Red-highlighted safety instructions for client |
| 3-4 | BNS Legal Analysis | Table of charges: Section / Old IPC / Punishment / Bailable? |
| 5 | Case Strategy | Strength rating, evidence checklist, predicted defence arguments |
| 6-7 | Draft FIR | Print-ready police complaint with signature lines |
| 8-9 | Legal Notice | Letterhead-formatted legal notice ready to post |
| 10 | Police Help Report | Plain-language narrative for the SHO |
| 11 | Disclaimer | "Generated by AI — must be reviewed by a licensed Advocate" |

---

## How We Will Build It (Phase 2 Code Plan)

### Library: `fpdf2`
- Already installed in `requirements.txt`
- Can embed fonts, draw tables, add page headers/footers, generate multi-page PDFs

### New File: `pdf_generator.py`
```
legal_ai/
├── main.py               ← Phase 1 (runs triage, saves text output)
├── pdf_generator.py      ← Phase 2 (reads text output, generates PDF)
├── assets/
│   ├── logo.png          ← Law firm logo placeholder
│   └── hindi_font.ttf    ← Devanagari font for Hindi sections
```

### Phase 2 Code Steps:
1. **Read** the saved `.txt` output from `outputs/` folder (Phase 1 already saves this)
2. **Parse** the six sections using the heading markers we defined
3. **Configure** FPDF with custom fonts, colors, and margins
4. **Render** each section with appropriate styling:
   - Red panels for advisory (urgent)
   - Blue headers for legal sections
   - Monospace font for FIR text (court-style)
   - Green table for BNS charge sheet
5. **Add** page numbers, date, and "CONFIDENTIAL" watermark
6. **Save** as `outputs/CaseBrief_[ClientName]_[Date].pdf`

---

## What Makes This Sellable

The PDF will look like it was prepared by a senior associate, not printed from
an email. Law firms can:

- **Brand it** with their own letterhead (logo + firm name configurable in `.env`)
- **File it** directly in their physical case folders
- **Send it** to clients as a professional first advisory document
- **Present it** in court as a drafted document for the lawyer to review
