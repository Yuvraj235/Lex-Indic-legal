Install the Lex-Indic Word add-in

Convert IPC pleadings to BNS without leaving Microsoft Word. The add-in lives in Word's task pane: select any text, click Convert IPC → BNS, and every IPC reference gets highlighted yellow with the BNS equivalent inserted right next to it. Original formatting preserved. Ctrl+Z undoes the whole conversion in one step.

1 Download the manifest

This XML file tells Word where to load the add-in from. Save it somewhere you can find again (e.g. ~/lexindic-addin/).

⬇ Download manifest.xml Open in browser

2 Start the Lex-Indic backend with HTTPS

Office Add-ins require HTTPS for every URL they load. We've generated a self-signed dev certificate at certs/dev-cert.pem so you can run locally without any cloud setup.

# From the project root
python3 app.py --https

# The server now serves at:
https://localhost:8443

The first time you open https://localhost:8443 in a browser, you'll see a certificate warning — click "Advanced" then "Proceed to localhost". You only need to do this once per browser. Word will accept the cert automatically after that.

3 Sideload the add-in into Word

Word for Mac:

  • Open Word.
  • Insert menu → Add-ins → My Add-ins.
  • Click the gear/settings icon → Upload My Add-in.
  • Pick the lexindic-manifest.xml from step 1.

Word for Windows:

  • Open Word.
  • Insert tab → Add-ins → My Add-ins.
  • Click Upload My Add-in at the bottom.
  • Pick the lexindic-manifest.xml from step 1.

Word for the web (Microsoft 365):

  • Open any doc on word.office.com.
  • Home tab → Add-ins → More add-ins.
  • Switch to My Add-ins → Manage My Add-ins → Upload My Add-in.

4 Use it

You should now see a Lex-Indic group on Word's Home ribbon, with a Convert IPC → BNS button. Click it.

  • The task pane opens on the right.
  • Pick Whole document or Current selection.
  • Click Convert →.
  • Every IPC reference in the active range is highlighted yellow and the BNS equivalent inserted in bold red right after it.
  • Sections we don't have a verified mapping for stay plain text — your visual signal that the converter has not silently invented.
  • Press Ctrl + Z (Cmd + Z on Mac) to undo the entire conversion in one step.
Your document never leaves your machine. The add-in calls https://localhost:8443/convert/text — the Flask backend running on this computer. No Lex-Indic cloud, no third parties. Air-gap deployments are supported with the --host 127.0.0.1 flag.
Troubleshooting: If the task pane fails to load with a blank window or "We couldn't load this add-in":
  • Make sure python3 app.py --https is running and https://localhost:8443/addin/taskpane opens in your browser without errors.
  • Trust the self-signed cert in your browser first (step 2).
  • On macOS Word, also trust the cert in Keychain Access: double-click certs/dev-cert.pem → set "When using this certificate" to "Always Trust".
  • Restart Word after trusting the cert.
